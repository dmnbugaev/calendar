# Исследование API расписания Московского Политеха (rasp.dmami.ru)

Дата исследования: 2026-11-10. Все факты проверены реальными запросами в этой сессии.

## Endpoint

```
GET https://rasp.dmami.ru/site/group?group=<ГРУППА>&session=0
```

- `session=0` — обычный семестровый режим. `session=1` для группы 251-362 сейчас
  возвращает `{"status":"error","message":"Не нашлось расписание для группы"}`
  (сессии нет). Поддерживаем только `session=0`.
- Несуществующая группа / нет расписания:
  `{"status":"error","message":"Еще не готово расписание для группы"}` (HTTP 200!).

## Заголовки

- `Referer: https://rasp.dmami.ru/` — **обязателен**, без него сервер отвечает HTTP 500.
  (Браузер шлёт его автоматически для same-origin AJAX.)
- `User-Agent` — обязателен (любой валидный).
- `X-Requested-With: XMLHttpRequest` — не обязателен.

## Структура ответа (fixture: `fixtures/rasp-group-251-362.json`)

```jsonc
{
  "status": "ok",
  "isSession": false,
  "group": {
    "title": "251-362",
    "course": 2,
    "dateFrom": "2026-09-01",   // начало семестра (YYYY-MM-DD)
    "dateTo": "2027-01-10",     // конец семестра
    "evening": 0,               // таблица времён пар: 0 | 1 | 2
    "comment": null
  },
  "grid": {
    "1": { "1": [Lesson], "2": [Lesson], ..., "7": [Lesson] },  // дни 1..6 = Пн..Сб
    ...                                                          // слоты 1..7
  }
}
```

Lesson (ровно 13 полей в fixture):

| Поле | Тип | Пример |
|---|---|---|
| `sbj` | string | «Математическая логика и теория алгоритмов в практике программирования» |
| `teacher` | string | «Набебин Алексей Александрович» (может быть пустым) |
| `teachers` | `[{id:number, name:string}]` | может быть пустым |
| `dts` | string | «01 Сен - 01 Ноя» (человекочитаемо, для отображения) |
| `df` | string | «2026-09-01» — дата начала диапазона занятия |
| `dt` | string | «2026-11-01» — дата конца диапазона занятия |
| `auditories` | `[{title, color}]` | title может содержать HTML: `<a href="...">📷 Webinar</a>` |
| `shortRooms` | array | в fixture всегда пусто |
| `location` | string | «Webinar», «ПД» (plain) |
| `type` | string \| null | «Лекция», «Практика», «Лаб. работа» |
| `week` | string | в fixture всегда `""` |
| `align` | string | «left» / «center» |
| `e_link` | string \| null | внешняя ссылка |

Проверено на 65+ группах: сейчас все занятия имеют `week: ""`.

## Времена пар (из `js/main.js` сайта, evening = group.evening)

- evening 0: 1: 9:00-10:30, 2: 10:40-12:10, 3: 12:20-13:50, 4: 14:30-16:00,
  5: 16:10-17:40, 6: 17:50-19:20, 7: 19:30-21:00
- evening 1: 6: 18:20-19:40, 7: 19:50-21:10 (остальные как в 0)
- evening 2: 6: 18:30-20:00, 7: 20:10-21:40 (остальные как в 0)

Время московское (`Europe/Moscow`, с 2014 г. без перехода на летнее время — фиксированный
UTC+3, что позволяет однозначно сериализовать в `+03:00`).

## Чётность недель

- Сайт добавляет значение `lesson.week` как CSS-класс занятия; в CSS есть
  `.lesson_week_even` (фон #fdffe0) и `.lesson_week_odd` (фон #e4e4e4).
- Логики вычисления чётности в клиентском JS нет — сайт только помечает занятия.
- Живых данных с непустым `week` сейчас нет (проверено 65+ групп).

**Решение (документированное допущение):** парсер принимает значения
`""`, `"odd"`, `"even"`, `"lesson_week_odd"`, `"lesson_week_even"`; любое другое значение —
ошибка валидации (синхронизация не запускается). Привязка к датам: учебные недели
считаются от начала семестра (`group.dateFrom`), первая учебная неделя — «нечётная»
(стандартная российская конвенция). Если университет начнёт помечать чётность,
правило нужно сверить с реальным отображением сайта.

## Отменённые и перенесённые занятия

В текущей структуре ответа **нет** отдельных флагов отмены/переноса. Отмена занятия
выражается только тем, что оно исчезает из `grid` (или его диапазон `df`/`dt` перестаёт
покрывать дату). Синхронизатор обрабатывает это как удаление события по ключу занятия.
